# Shopee Video โพสต์ช่วย (Android ต่อสาย USB)

## หน้า UI

ดับเบิลคลิก **start.bat** เพื่อเปิดหน้า UI ที่ `http://127.0.0.1:8765` หากเปิดอยู่แล้ว จะเปิดหน้าเดิมให้

1. เลือก **มือถือที่จะใช้** แล้วกด **ตรวจมือถือที่เลือก** ต้องพบ Shopee และอ่านหน้าจอได้
2. กด **ตรวจรหัสจากลิงก์ทั้งหมด** — แสดง Item ID และ Shop ID ในคิวคลิป
3. กด **เริ่มเตรียมโพสต์** เพื่อส่งคลิป ใส่แคปชัน และปักสินค้า ค่าเริ่มต้นให้ผู้ใช้กดโพสต์เอง
4. ก่อนโพสต์ โปรแกรมเทียบ Item ID กับสินค้าที่ปัก หากรหัสไม่ตรงหรือยังอ่านไม่ได้ จะหยุดรอ ไม่เลือกผลค้นหาตัวแรกให้โดยไม่มีหลักฐานรหัส
5. ถ้าหน้าจอ Shopee ซ่อนรหัส ให้เปิดรายละเอียด **สินค้าที่ปักไว้** บนมือถือ แล้วกด **r** ในช่องคำตอบ หรือวางลิงก์ที่คัดลอกจากสินค้านั้น เมื่อตรวจตรงแล้วให้กลับหน้าโพสต์และกด **ทำแล้ว · ไปต่อ**

ปุ่ม **ตรวจสินค้าบนมือถือ** ใช้เทียบหน้ารายละเอียดสินค้าที่เปิดอยู่กับคลิปที่เลือกได้โดยไม่เริ่มโพสต์ โดยอ่านรหัสจากหน้าจอหรือคัดลอกลิงก์แชร์สินค้า ไม่ส่งข้อความให้ใคร

เสียบมือถือ Android เครื่องอื่นแล้วกด **ค้นหามือถือใหม่** ทุกเครื่องต้องเปิด USB debugging และอนุญาตคอมนี้ หากมีเครื่องพร้อมหลายเครื่อง ต้องเลือกเครื่องให้ชัดเจนก่อนเริ่ม ขั้นตอนที่สอนจะเก็บแยกต่อเครื่องใน `flows/` และระหว่างทำงานจะล็อกเครื่องที่เลือกไว้

คำสั่งเดิมยังใช้ได้: `start.bat check`, `start.bat post`, `start.bat dump` หรือ `start.bat menu` เพื่อเปิดเมนูข้อความ

เอาคลิปที่ extension **meta-helper** โหลดไว้ใน `Downloads/ShopeeVideo` (คลิป `.mp4` + ไฟล์ `.txt` แคปชัน/แฮชแท็ก/ลิงก์)
ส่งเข้ามือถือ แล้วกดแอป Shopee ให้ทีละคลิป:

เปิดแอป → แท็บวิดีโอ → สร้าง → เลือกคลิป → ถัดไป → ใส่แคปชัน + แฮชแท็ก → **เพิ่มสินค้า (ปักตะกร้า)** ด้วยลิงก์ affiliate → โพสต์

- ค่าเริ่มต้น: **เตรียมให้ครบ แล้วเรากดโพสต์เอง** (ปลอดภัยกว่า) · อยากให้กดโพสต์เองด้วย → `auto_post: true`
- ใช้ได้กับ Android เท่านั้น (iPhone ไม่ได้)

## ติดตั้ง (ครั้งเดียว)
1. **มือถือ**: ตั้งค่า → เกี่ยวกับโทรศัพท์ → แตะ "หมายเลขบิลด์" 7 ครั้ง → ตัวเลือกสำหรับนักพัฒนา → เปิด **การแก้ไขข้อบกพร่อง USB**
   - Xiaomi / Redmi / POCO: เปิด **การแก้ไขข้อบกพร่อง USB (การตั้งค่าความปลอดภัย)** ด้วย (ไม่งั้นกดแทนไม่ได้)
2. เสียบสาย USB (สายที่ส่งข้อมูลได้) → บนมือถือกด **อนุญาต** + ติ๊ก "อนุญาตจากคอมนี้เสมอ"
3. แตกไฟล์ ZIP ไว้ที่ไหนก็ได้ → ดับเบิลคลิก **`start.bat`** (ครั้งแรกจะลงโปรแกรมเสริมให้เอง ต้องมี Python)
4. ในหน้า UI เลือกเครื่องแล้วกด **ตรวจมือถือที่เลือก** ให้ผ่านครบ

## ใช้งาน
1. ใช้ extension ทำคลิปตามปกติ (คลิปไปอยู่ใน `Downloads/ShopeeVideo`)
2. เสียบมือถือ ปลดล็อกจอ → ดับเบิลคลิก `start.bat` → เลือกเครื่อง ตรวจมือถือและรหัสจากลิงก์ → **เริ่มเตรียมโพสต์**
3. โปรแกรมทำให้ทีละคลิป · ทำตามคำถามในช่อง **บันทึกการทำงาน** จนตรวจ Item ID ตรง พอเตรียมเสร็จ ตรวจบนมือถือแล้วกด **โพสต์** เอง → กลับมากด **ทำแล้ว · ไปต่อ** ใน UI
4. พักแบบสุ่มระหว่างคลิป แล้วทำคลิปถัดไป · จำว่าคลิปไหนโพสต์แล้ว (ไม่โพสต์ซ้ำ)

> ระหว่างทำงาน **อย่าแตะมือถือ** (ยกเว้นตอนโปรแกรมบอกให้กด) · เปิดจอค้างไว้ ไม่ให้ล็อก

## โหมดสอน (ครั้งแรกจะเจอแน่)
ผมไม่รู้ชื่อปุ่มจริงในแอป Shopee ของแต่ละเครื่อง — ถ้าโปรแกรมหาปุ่มไม่เจอ จะขึ้นแบบนี้:

```
🟡 หา “กดปุ่มสร้าง/อัปโหลดวิดีโอ” ไม่เจอบนหน้าจอ
   ปุ่ม/ช่องบนจอมือถือตอนนี้:
    1) “สำหรับคุณ” · ข้อความ · บนกลาง
    2) [ไอคอนไม่มีชื่อ] · ปุ่ม · บนขวา
    3) “Video” · ปุ่ม · ล่างซ้าย
   พิมพ์เลขที่ต้องกด (โปรแกรมจะจำไว้) · Enter = กดเองบนมือถือแล้วไปต่อ · r = ดูจอใหม่ · s = ข้ามขั้นนี้ · q = หยุด:
```
- พิมพ์ **เลข** ของปุ่มที่ถูก → โปรแกรมกดให้ และ **จำไว้ใช้ครั้งต่อไป** (บันทึกใน `flow.json`)
- ไม่เจอในรายการ → กดเองบนมือถือ แล้วกด **Enter** (ครั้งนี้ไปต่อได้ แต่ยังไม่จำ)
- หน้าจอเพิ่งเปลี่ยน → พิมพ์ **r** ดูใหม่
- สอนครบ 1–2 คลิปแรก หลังจากนั้นจะวิ่งเองทั้งหมด
- แอป Shopee อัปเดตแล้วปุ่มเปลี่ยน → มันจะถามใหม่เฉพาะปุ่มที่เปลี่ยน · อยากล้างทั้งหมด → เมนู **5**

## ตั้งค่า (`settings.json` — เมนู 4)
| ค่า | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `clips_folder` | โฟลเดอร์คลิป | `Downloads\ShopeeVideo` |
| `auto_post` | `true` = กดโพสต์ให้เอง | `false` |
| `daily_limit` | โพสต์ไม่เกินวันละ | `8` |
| `delay_minutes` | พักสุ่มระหว่างคลิป (นาที) | `[4, 9]` |
| `product_search` | ปักตะกร้าด้วย `link` (ลิงก์ affiliate) หรือ `name` (ชื่อสินค้า) · ค้นลิงก์ไม่เจอจะลองชื่อให้เอง | `link` |
| `delete_after_post` | ลบคลิปที่ส่งเข้ามือถือหลังโพสต์ (เฉพาะไฟล์ `sv_…mp4` ของโปรแกรมนี้) | `true` |
| `popups` | ข้อความปุ่มของหน้าต่างเด้งที่ให้กดปิดเอง | อนุญาต / ตกลง / … |

## กันพลาด
- ปิดหน้าต่างเด้ง (ขออนุญาต / แนะนำ) ให้เอง ก่อนกดปุ่มข้างหลัง
- ปักตะกร้าไม่สำเร็จ → **ไม่กดโพสต์ให้** แม้เปิด `auto_post` (หยุดให้ตรวจก่อน)
- ข้ามไฟล์ `.webm` และไฟล์ท่อนย่อย (`-1`, `-2`) · คลิป `-A` / `-B` ใช้แคปชันจาก `ชื่อสินค้า.txt` ไฟล์เดียวกัน
- โพสต์แล้ว / กดข้ามแล้ว จะไม่เสนอซ้ำ (เก็บใน `posted.json` — ลบไฟล์นี้ถ้าอยากเริ่มนับใหม่)

## ⚠ ความเสี่ยง
Shopee ห้ามใช้บอท/ระบบอัตโนมัติ ถ้าโพสต์ถี่หรือดูเป็นเครื่องจักร บัญชี affiliate อาจโดนระงับ (ค่าคอมค้างอาจหาย)
→ เริ่มจากโหมดกดโพสต์เอง · ไม่เกินวันละ 5–10 คลิป · ใช้ช่วงพักแบบสุ่ม

## มีปัญหา
- เมนู **3) ดูปุ่มบนหน้าจอมือถือตอนนี้** → ได้ไฟล์ `dumps/screen_….txt` (รายชื่อปุ่ม) ส่งให้ผู้พัฒนาดูได้
  (ไฟล์ `.png` เป็นรูปหน้าจอ อาจมีข้อมูลส่วนตัว ส่งเฉพาะถ้าจำเป็น)
- พิมพ์ภาษาไทยไม่เข้า / กดไม่ได้ บน Xiaomi → เช็ก "USB debugging (Security settings)"
- ไม่เจอมือถือ → เปลี่ยนสาย/พอร์ต USB · ปลดล็อกจอ · กดอนุญาตบนมือถือ
