โปรแกรมรอคุณตอบ

ตรวจมือถือก่อนเริ่ม เพื่อเช็กการควบคุม หน้าจอ และแอป Shopee

ตรวจความพร้อมมือถือ

เชื่อมมือถือ Android เครื่องอื่น
  1. เสียบสาย USB ที่ส่งข้อมูลได้ และปลดล็อกจอ
  2. เปิดตัวเลือกสำหรับนักพัฒนา → USB debugging
  3. กดอนุญาตคอมเครื่องนี้บนมือถือ แล้วกดค้นหามือถือใหม่
  4. เลือกเครื่องจากรายการ แล้วกดตรวจมือถือที่เลือก
เปิดตัวเลือกนักพัฒนาบน Samsung

ตั้งค่า → เกี่ยวกับโทรศัพท์ → ข้อมูลซอฟต์แวร์ → แตะ Build number 7 ครั้ง

คู่มือ Samsung

Xiaomi / Redmi / POCO อาจต้องเปิด USB debugging (Security settings) ด้วย

ตรวจรหัสสินค้าที่ปัก

เทียบ Item ID กับลิงก์ของคลิป

เปิดรายละเอียดสินค้าที่ปักไว้บนมือถือ แล้วกดตรวจ โปรแกรมจะอ่านรหัสหรือคัดลอกลิงก์สินค้านั้นมาเทียบ

ยังไม่ได้เทียบกับสินค้าบนมือถือ
