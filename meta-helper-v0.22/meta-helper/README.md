# Shopee Video ผู้ช่วยทำคลิป (ส่วนเสริม Chrome / Edge สำหรับ meta.ai)

## ขั้นตอน
1. **Shopee Affiliate → ข้อเสนอ ผลิตภัณฑ์**: กด **＋ คิวคลิป** ข้างปุ่ม “เอา ลิงก์” → เก็บชื่อ/รูป/ค่าคอม เข้าคิว และเก็บลิงก์ affiliate ให้
   (หน้าสินค้า Shopee ปกติมีปุ่ม “＋ ส่งเข้าคิวทำคลิป” มุมขวาล่าง)
2. **meta.ai**: กด **🎬 Shopee Video** → แท็บ **ตั้งค่าคลิป**: ความยาว สไตล์ ผู้แสดง พรีเซนเตอร์ บทพูดไทย
3. แท็บ **คิวสินค้า**: ทุกตัวในคิวจะถูกทำคลิป ตัวไหนไม่เอากด 🗑
4. กด **▶ รันคิวอัตโนมัติ** (ดูหัวข้อถัดไป) · ตอนโพสต์กด **📋 ลิงก์ affiliate**

## รันคิวอัตโนมัติ (ทดลอง)
ทำทีละสินค้า: แนบรูป + ใส่ prompt → กดส่ง → รอคลิปเสร็จ (สูงสุด 6 นาที) → ดาวน์โหลด → ขึ้น ✅ เสร็จ → พัก (ตั้งได้: ไม่พัก / 5 / 15 / 30 วิ · ค่าเริ่มต้น 5) → สินค้าถัดไป
- **15 / 20 วิ = ได้ไฟล์เดียว**: สั่ง meta.ai ทำทีเดียวทั้งคลิป ถ้าทำเป็นท่อนให้รวมเป็น mp4 ไฟล์เดียวเอง (ffmpeg) · ถ้า meta.ai ส่งมาเป็น 2 ท่อน extension รวมในเครื่องแล้วเก็บแค่ไฟล์รวม (รวมไม่ได้จริงๆ ถึงจะโหลด 2 ท่อนกันหาย)
- **แบ่งเป็นช่วง**: 10 วิ = 3 ช่วง (0–2 / 2–6 / 6–10) · 15/20 วิ = 4 ช่วง โดย **ช่วง 1–3 จบที่วิ 10 พอดี** (meta.ai ต่อคลิปหลัง 10 วิ ภาพมักไม่ต่อเนื่อง) ช่วง 4 = 10–15 (หรือ 10–20) เป็นช็อตใหม่ ให้รอยตัดดูตั้งใจ · บทพูดใส่แยกตามช่วง
- ไฟล์อยู่ใน **`Downloads/ShopeeVideo/ชื่อสินค้า.mp4`** (โฟลเดอร์ดาวน์โหลดของ Chrome) · กดปุ่ม **📂** ข้างปุ่มรันเพื่อเปิดโฟลเดอร์
- ตัวไหนผิดพลาด → ข้ามไปตัวถัดไป · กด **⏹ หยุด** ได้ตลอด · ดูสถานะในช่องบันทึกด้านล่างแผง · ตัวที่เสร็จแล้วกด **↺ ทำใหม่** ได้
- **เปิดแท็บ meta.ai ค้างไว้บนจอ** (ถ้าย่อ/สลับแท็บนาน Chrome จะหน่วงการทำงาน) · ถ้ารีเฟรชหน้าระหว่างรัน คิวจะหยุด
- ปุ่มส่ง/วิดีโอบน meta.ai ยังเป็นแบบเดา ถ้าไม่ทำงานให้แคปหน้าจอส่งมาเพื่อปรับ
- ใช้ระบบอัตโนมัติกับ meta.ai อาจขัดเงื่อนไขการใช้งาน ใช้ความเสี่ยงของตัวเอง

## ของที่ได้ต่อสินค้า (v0.17)
- **คลิปต่อสินค้า**: 1 คลิป หรือ **2 แบบ (A/B)** ไว้เลือกตัวที่ดีกว่า — แบบหนึ่งพลาด อีกแบบยังทำต่อ
- **ไฟล์ข้อความโพสต์** `ชื่อสินค้า.txt`: แคปชันเป็นกันเอง + แฮชแท็ก (Gemini เขียนพร้อมบท ไม่เปลืองโควตา · ตัดคำต้องห้ามออก) + ลิงก์ affiliate
- **ล้างไฟล์เก่าใน meta.ai** (ติ๊กเปิด/ปิด · ค่าเริ่มต้นทุก 5 คลิป): พื้นที่ทำงานของ meta.ai จำกัด ~500MB ไฟล์เก่าค้างจนรวมคลิป 20 วิไม่ได้ → ทำครบตามจำนวนจะส่งข้อความแยกสั่งลบไฟล์เก่า (ไม่ทำวิดีโอ) · เลือก “ทุกคลิป” = ใส่คำสั่งล้างใน prompt ทุกตัว
- **รอ meta.ai ว่างก่อนส่ง**: ถ้ายังมีงานก่อนหน้า (ปุ่มหยุด/กำลังสร้าง) จะรอให้เสร็จก่อน (สูงสุด 5 นาที) แทนการกดส่งตอนปุ่มยังล็อก
- **หาปุ่มส่งอย่างระวัง**: ปุ่ม Send/ส่ง มาก่อน · ไม่แตะปุ่มแนบไฟล์/รูป/โหมด/เมนู · ถ้ากดโดนปุ่มที่เปิดหน้าต่างเลือกไฟล์ จะกันไม่ให้เด้ง แล้วจำปุ่มนั้นไว้ไม่กดอีก (ล้างรายการได้ในแท็บตั้งค่า) · ไม่มีปุ่มที่มีชื่อ → ลองปุ่มไอคอนขวาสุด
- **🔍 คัดลอกข้อมูลหน้าเว็บ** (ปุ่มเล็กข้างปุ่มรัน): คัดลอกชื่อ/ตำแหน่งปุ่มรอบช่องพิมพ์ + จำนวนวิดีโอ (ไม่มีข้อความแชต/ลิงก์เต็ม) ส่งให้ผู้พัฒนาปรับตัวจับปุ่ม
- **ความคมชัด**: ปกติ / คมชัดสูง (ค่าเริ่มต้น) / คมชัดสูงสุด — ขอใน prompt ความละเอียดไฟล์จริง meta.ai กำหนด
- **ไม่โหลดคลิปเก่าซ้ำ**: meta.ai วาดหน้าใหม่บ่อย คลิปเก่าจะได้ลิงก์ใหม่ → ระบบแยกด้วยเนื้อไฟล์ (hash) + เอาเฉพาะวิดีโอที่อยู่หลัง prompt ที่เพิ่งส่ง · จำคลิปที่เคยเห็น/เคยโหลดไว้ข้ามการรีเฟรช
- **ทำต่อหลังรีเฟรช**: ถ้าหน้า meta.ai โหลดใหม่ระหว่างรัน → ทำต่อเองใน 10 วิ (กด ⏹ ยกเลิกได้)
- **รายละเอียดสินค้า**: ดึงจากหน้าสินค้า Shopee (หน้า Affiliate จะลองดึงเบื้องหลัง) · แก้เองได้ (กดรูปปกการ์ด) → Gemini ใช้เขียนบทให้ตรงขึ้น
- **สถิติวันนี้** (บนสุดแท็บคิว): สินค้าเสร็จ / พลาด · ไฟล์คลิป · จำนวนครั้งที่เรียก Gemini
- prompt สั่งให้ **ออกเสียงไทยถูกต้อง ชัด สำเนียงคนไทย** และตัวหนังสือไทยต้องสะกดถูก ไม่ชัวร์ให้ไม่ใส่

## บทพูดอัตโนมัติ (Gemini · ฟรี)
1. เอา API key ฟรีที่ https://aistudio.google.com → **Get API key**
2. แท็บ **ตั้งค่าคลิป** → บทพูด → **✨ Gemini เขียนให้ทีละสินค้า** → วาง key (เก็บในเครื่องนี้เท่านั้น ไม่ต้องส่งให้ใคร)
3. ตอนรันคิว: สินค้าที่ยังไม่มีบท → Gemini เขียนบทไทยจากชื่อ + รูป (ความยาวตาม 10/20 วิ, โทนเสียงตามที่เลือก)
   → บทเป็นกันเอง เหมือนเล่าให้เพื่อนฟัง (ใช้ "เรา" ไม่มีครับ/ค่ะ เข้ากับเสียงทุกเพศ) **1 บรรทัด = 1 ช่วง** ยาวพอดีช่วง (จังหวะเร็ว ≈ 7–8.5 ตัวอักษร/วิ: 15 วิ ≈ 105–130 ตัวอักษร) ไม่มีประโยคคร่อมรอยตัดวิที่ 10
   → **ขึ้นต้นไม่ซ้ำกัน**: หมุนแบบเปิดคลิป 8 แบบ (คำถาม / POV / ปัญหา→ทางแก้ / บอกต่อ / ตอนใช้งาน / เทียบแบบเดิม / จุดเด่นที่เห็น / ลองครั้งแรก) + ส่งประโยคเปิดของตัวอื่นให้ห้ามซ้ำ · ห้ามขึ้นต้นด้วยคำอุทาน (เฮ้ย โห ว้าว …) ถ้ายังมีจะตัดทิ้งเอง
   → ตรวจคำต้องห้าม ถ้าเจอให้เขียนใหม่ (สูงสุด 3 รอบ)
- **เลือกรุ่นอัตโนมัติ**: ถามรุ่นที่ key ใช้ได้จาก Google แล้วกระจายหลายเวอร์ชัน (ปกติ + lite) · รุ่นไหนแน่น (503) / โควตาเต็ม (429) ข้ามไปรุ่นถัดไปทันที · **จำรุ่นที่ตอบได้** ไว้ใช้ก่อนครั้งหน้า · ทุกรุ่นไม่ว่าง พักแล้ววนใหม่ 3 รอบ ถ้าไม่ได้เลย ทำคลิปต่อโดยไม่กำหนดบท
- กันโดน rate limit: รุ่นเดียวกันเว้น ≥ 6.5 วิ (โควตาฟรีคิดแยกตามรุ่น) · ทุกคำขอเว้น ≥ 1 วิ
- ปุ่ม **🔌 ทดสอบ key + รุ่น**: บอกว่า key ใช้ได้ไหม แล้วไล่รุ่นจนเจอตัวที่ตอบ (จำไว้ใช้ก่อน) · error แสดงข้อความเต็มจาก Google
- แท็บคิวสินค้า: **✨ เขียนบททั้งหมด** (ตัวที่ยังไม่มีบท + บทที่ Gemini เขียนไว้สำหรับความยาว/จังหวะอื่น · ทีละตัว เว้นระยะกันโดน rate limit · กดซ้ำ = หยุด) หรือ **✨ เขียนบท** รายตัว
- แก้บทเองได้ (แก้แล้วจะไม่ถูกเขียนทับ · แบ่งบรรทัดตามช่วงจะใส่ตรงจังหวะ) · บทที่มีคำต้องห้ามจะไม่ถูกส่ง
- key จาก AI Studio แบบใหม่ขึ้นต้น `AQ.` (แบบเก่า `AIza`) ใช้ได้ทั้งคู่
- การ์ดสินค้าแบบย่อ: กดรูปปกเพื่อกาง/พับรูปทั้งหมด (ลบ/เพิ่มรูป)
- ใช้ key ฟรี Google อาจเอาข้อมูลที่ส่งไปใช้ปรับปรุงระบบ (ส่งแค่ชื่อสินค้า + รูปสินค้า)

## ตัวเลือก
- **ความยาว** 10 / 15 / 20 วิ
- **จังหวะ** เร็ว (ค่าเริ่มต้น: พูดไว ตัดภาพทุก 0.5–1 วิ + เพลงคลอ) / ปกติ (ตัดทุก 2–3 วิ)
- **จำนวนซีน** อัตโนมัติ / 3 / 4 / 5 / 6 / 8 ซีน (คลิปเกิน 10 วิ บังคับเปลี่ยนซีนที่วิ 10)
- **เสียงธรรมชาติ**: สั่งให้เป็นเสียงคนจริงอัดคลิปเล่าให้เพื่อนฟัง ไม่ใช่เสียงผู้ประกาศ/โฆษณา · บทใช้คำพูดจริงๆ (โห อื้อ แบบ เลย)
- **ลูกเล่นภาพ** (เลือกได้หลายอัน) อัตโนมัติ / ซูมกระแทก / ปัดเปลี่ยนฉาก / เร่ง-สโลว์ / ภาพค้าง+แฟลช / แบ่งจอ / สั่นตามจังหวะ / ไม่ใส่ — มีเสียงประกอบ (วูช ป๊อป)
- **prompt ภาษาอังกฤษ แบ่งหมวด**: [VIDEO] [REFERENCE IMAGES] [SCENE] [PRESENTER] [STORY] [ON-SCREEN TEXT] [PRODUCT LOCK] [RULES — MUST FOLLOW] (ภาษาไทยมีเฉพาะที่พิมพ์เอง: ชื่อสินค้า ฉาก บทพูด ข้อความบนจอ)
- **สไตล์** อัตโนมัติ / มินิมอล / ธรรมชาติ · **การเห็นผู้แสดง** อัตโนมัติ / เห็นทั้งตัว / เห็นแค่มือ / ไม่เห็นคน · **ผู้แสดง** อัตโนมัติ / คน / สัตว์
- **แนวสำเร็จรูป**: 🏠 สินค้าในห้อง + ลายมือชี้จุดเด่น (ธรรมชาติ · ไม่เห็นคน · เป็นกันเอง · คำเด่น + ลายมือ/ลูกศร · ห้องโทนครีมสว่าง เห็นบรรยากาศห้อง ไม่เบลอฉากหลัง)
- **โทนเสียง** อัตโนมัติ (= เป็นกันเอง) / สดใส / นุ่มนวล / ตื่นเต้น / เป็นกันเอง / มืออาชีพ / กระซิบ ASMR
- **ตัวหนังสือบนจอ** ไม่มี / คำเด่นเด้ง / ซับบทพูด / หัวข้อเปิด · **ลูกเล่น** อัตโนมัติ / เด้ง / พิมพ์ทีละตัว / ไฮไลต์คำ / นีออน / ลายมือ + ลูกศร · ใส่ข้อความเองได้ (ตรวจคำต้องห้ามด้วย)
- จบด้วยบทพูด ไม่ชี้ตะกร้า
- **พรีเซนเตอร์** เก็บได้หลายคน (รูป + ชื่อ + คำบรรยาย) → เลือกแล้ว = ultra realistic + ล็อกหน้า + เสียงตามเพศ/อายุในรูป
- **ตรวจคำต้องห้าม** ในบทพูด/ฉาก (ราคา โปร ส่งฟรี ที่สุด อ้างสุขภาพ เด็ก) เตือนก่อนใส่ prompt
- ใส่ให้ทุกครั้ง: แนวตั้ง 9:16 · ภาษาไทยเท่านั้น · ล็อกสินค้า · ห้ามพูด/ห้ามโชว์ ราคา โปร ส่วนลด · ห้ามมีเด็ก
