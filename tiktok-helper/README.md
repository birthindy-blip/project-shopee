# Meta AI → TikTok (ส่วนเสริม Chrome / Edge)

## เจนคลิปจากพรอมป์ต์ของคุณเอง

หน้าควบคุมแบ่งเป็น **บัญชีและการส่ง / สร้างคลิป / คลิปพร้อมส่ง / ประวัติ** ครั้งแรกจะพาไปเชื่อมบัญชี ส่วนแคปชันและรูปอ้างอิงพับเก็บไว้ในหน้าสร้างคลิป

### แบ่งคลิปหลายบัญชี

- เปิดใช้เฉพาะบัญชีที่ต้องการในแท็บ **บัญชีและการส่ง**
- ตอนเพิ่มพรอมป์ต์ เลือก **ส่งคลิปนี้ไปบัญชี** ได้เลย ถ้าเลือกแบ่งอัตโนมัติ จะเลือกบัญชีที่มีคลิปรอเจนน้อยที่สุด
- กด **แบ่งคลิปให้ทุกบัญชี** เพื่อจัดปลายทางของคลิปที่ยังรอใหม่ให้เท่า ๆ กัน เช่น 7 คลิป / 3 บัญชี = 3, 2, 2 คลิป ไม่ทำสำเนาไปทุกบัญชี
- เปลี่ยนบัญชีรายคลิปได้ในคิว และกรองดูคิวเฉพาะบัญชีได้
- บัญชีที่ปิดใช้หรือ token หมดอายุจะไม่ถูกนำมาแบ่ง ถ้าคลิปมีปลายทางอยู่แล้วแต่บัญชีนั้นไม่พร้อม/ติดเพดาน จะเก็บปลายทางเดิมและหยุดให้ตรวจ ไม่ย้ายคลิปไปบัญชีอื่นเอง
- แท็บ **คลิปพร้อมส่ง** กรองตามบัญชีและเปลี่ยนปลายทางก่อนอัปโหลดได้

ตรวจโค้ดด้วย `node --test meta-content.test.cjs routing.test.cjs account-routing.test.cjs` ส่วน `node ui-preview.cjs` เปิดหน้าตัวอย่างที่ `http://127.0.0.1:8876` ใช้ข้อมูลจำลองสำหรับตรวจ UI เท่านั้น ไม่เจนหรือโพสต์จริง

ส่วนเสริมนี้ไม่มีระบบดึงสินค้า Shopee หรือเขียนบทสินค้า คุณพิมพ์พรอมป์ต์เองได้ทุกแนว

1. Load unpacked โฟลเดอร์ `tiktok-helper` (ถ้าติดตั้งอยู่แล้ว กด Reload) และรีเฟรชแท็บ Meta AI
2. กดไอคอนส่วนเสริมเพื่อเปิดหน้าควบคุม → กด **เปิด Meta AI** และล็อกอิน เลือกหน้าที่สร้างวิดีโอได้
3. ใส่ชื่อคลิป พรอมป์ต์ แคปชัน และรูปอ้างอิงถ้าต้องการ → **เพิ่มเข้าคิวเจน** ทำซ้ำได้หลายคลิป
4. กลับหน้าควบคุม กด **ตรวจแท็บ** และเลือกแท็บ Meta AI → **เริ่มคิวเจน**
5. คลิปจะถูกเก็บในส่วนเสริมและเพิ่มเข้ารายการอัปโหลดด้านล่าง ถ้าติ๊ก **อัปโหลดไป TikTok หลังเจนเสร็จ** จะส่งตามบัญชีและโหมดที่ตั้งไว้ พร้อมเว้นระยะระหว่างคลิป

ต้องเปิดหน้าควบคุมและแท็บ Meta AI ค้างไว้ หยุดคิวของ Meta helper ตัวเดิมก่อนใช้ ห้ามพิมพ์หรือเจนงานอื่นในแท็บ Meta AI เดียวกันระหว่างรันคิว

- พรอมป์ต์ถูกส่งตามที่พิมพ์ ไม่มีการเติมบทหรือกฎสินค้าให้อัตโนมัติ ต้องระบุให้สร้างวิดีโอในพรอมป์ต์เอง
- รูปอ้างอิงรับ JPG/PNG/WebP ไม่เกิน 10 MB ถ้าหาช่องแนบรูปไม่พบ ให้เปิดเมนูแนบรูปบน Meta AI ก่อน
- รองรับคลิปที่หน้า Meta AI แสดงเป็น `<video>` และอ่านไฟล์ได้ ถ้าเว็บตอบเป็นข้อความ/รูป หรือโหลดวิดีโอไม่ได้ คิวจะหยุดและแสดงข้อผิดพลาด
- โค้ดตัวจับช่องพิมพ์ ปุ่มส่ง และวิดีโออ้างอิง `meta-helper-v0.22` แต่ยังต้องทดสอบกับหน้า Meta AI และบัญชีจริง เว็บเปลี่ยนโครงสร้างได้
- คลิปเก็บใน IndexedDB ของส่วนเสริม กู้กลับมาเมื่อเปิดหน้าควบคุมใหม่ได้ ไม่ดาวน์โหลดลง Downloads อัตโนมัติ ลบแถวคิวเจนเพื่อลบไฟล์ที่เก็บไว้
- เมื่อปิดหน้าระหว่างเจน จะไม่ส่งพรอมป์ต์ใหม่เอง กด **ตรวจ / ทำต่อ** เพื่อรับคลิปที่ค้างในแท็บเดิมก่อน ถ้าแท็บถูกรีเฟรช ไฟล์ที่ยังไม่ได้รับอาจหาย ต้องตรวจคลิปบนเว็บเองก่อนส่งใหม่
- ปุ่มหยุดยกเลิกการรอและหยุดเริ่มงานถัดไป ไม่ยกเลิกงานสร้างที่ Meta AI รับไปแล้ว หรือการอัปโหลด TikTok ที่เริ่มไปแล้ว
- คลิปจาก Meta AI ติดป้าย AI เสมอเมื่อโพสต์ตรง

### ข้อจำกัด TikTok

โหมดกล่องร่างอัปโหลดอัตโนมัติได้ แต่ต้องกดโพสต์เองใน TikTok โหมดโพสต์ตรงใช้ `video.publish` และถูกจำกัดตามสถานะแอป/บัญชี แอปที่ยังไม่ผ่านตรวจไม่สามารถโพสต์สาธารณะได้ จึงไม่รับประกันการโพสต์สาธารณะอัตโนมัติครบวงจร

TikTok ระบุว่าเครื่องมืออัปโหลดเฉพาะบัญชีของคุณหรือทีมไม่ใช่รูปแบบที่ยอมรับสำหรับการตรวจ Direct Post และกำหนดขั้นตอนเลือกข้อมูลโพสต์/ยินยอมก่อนส่ง ต้องพิจารณาข้อกำหนดเหล่านี้หากจะนำไปใช้งานจริงหรือขออนุมัติแอป:
[Content Sharing Guidelines](https://developers.tiktok.com/docs/en/content-sharing-guidelines) · [Direct Post](https://developers.tiktok.com/docs/en/content-posting-api-reference-direct-post)

## ระบบอัปโหลดเดิม

อัปโหลดคลิปในเครื่องขึ้น TikTok **หลายบัญชี** ผ่าน Content Posting API ทางการ (ฟรี) — แยกออกมาจาก meta-helper (ตัวนั้นไม่มี TikTok แล้ว)

## ติดตั้ง
1. เปิด `chrome://extensions` (หรือ `edge://extensions`) → เปิด **Developer mode** → **Load unpacked** → เลือกโฟลเดอร์ `tiktok-helper`
2. กดไอคอนส่วนเสริม → เปิดหน้า **TikTok Uploader** (ทำทุกอย่างในหน้านี้ · เปิดค้างไว้ระหว่างอัปโหลด)

## ตั้งค่าครั้งแรก (ฟรี · ทำครั้งเดียว)
1. developers.tiktok.com → Manage apps → ใช้แอปเดิมที่เคยต่อกับ meta-helper ได้ (หรือสร้างใหม่) → ต้องมี **Login Kit** + **Content Posting API**
2. **Login Kit → Redirect URI**: เพิ่มลิงก์ที่หน้า 🔑 ตั้งค่าแอป แสดง (กดคัดลอก) — ส่วนเสริมนี้เป็นตัวใหม่ **ลิงก์ไม่เหมือนของ meta-helper ต้องเพิ่มใหม่**
3. **Sandbox → Target users**: เพิ่มทุกบัญชี TikTok ที่จะใช้ (ตอนแอปยังไม่ผ่านตรวจ)
4. วาง **Client Key + Client Secret** → บันทึก → **➕ เพิ่มบัญชี TikTok** (หน้า TikTok เด้งให้กดอนุญาต)
   - เพิ่มอีกบัญชี: ล็อกอินบัญชีนั้นบน tiktok.com ในเบราว์เซอร์นี้ก่อน (หรือสลับบัญชีในหน้าต่างอนุญาต) แล้วกด ➕ อีกครั้ง
   - บัญชีที่เคยเชื่อมใน meta-helper ต้องเพิ่มใหม่ที่นี่ (คนละส่วนเสริม เก็บ token แยกกัน)
- Client Secret / token เก็บในเครื่องนี้เท่านั้น · token ต่ออายุเองได้ 1 ปี

## ใช้งาน
1. **เลือกคลิป**: ลากไฟล์มาวาง / 🎬 เลือกไฟล์ / 📁 เลือกทั้งโฟลเดอร์ (เช่น `Downloads/ShopeeVideo` ที่ meta-helper โหลดไว้)
   - รับ .mp4 / .mov / .webm · ไม่เอารูป
   - **แคปชันจาก .txt ชื่อเดียวกัน** (`ชื่อ.mp4` / `ชื่อ-A.mp4` / `ชื่อ (1).mp4` ↔ `ชื่อ.txt`) · ตัดบรรทัดลิงก์/🛒 พิกัดออก (TikTok กดลิงก์ไม่ได้) · ตัดแท็ก #Shopee… · ไม่มี .txt = ใช้ชื่อไฟล์ · แก้แคปชันในช่องได้
2. **บัญชี**: แต่ละคลิปได้บัญชีสลับกันทีละคลิป (👉 = คลิปถัดไปไปบัญชีนี้) · เปลี่ยนบัญชีรายคลิปได้ในช่องเลือก · กดชื่อบัญชี = เปิด/ปิดใช้ · 🗑 = เอาออก
3. **ส่งแบบ**
   - **📥 กล่องร่าง** (ค่าเริ่มต้น · ใช้ได้เลย): คลิปเข้ากล่องร่างในแอป TikTok แล้วกดโพสต์เอง (ใส่เสียงเทรนด์ได้) · กล่องร่างไม่รับแคปชันจาก API → กด **📋 แคปชัน** แล้ววางในแอป · ค้างได้ไม่เกิน 5 คลิปใน 24 ชม. ต่อบัญชี
   - **🚀 โพสต์ตรง**: ขึ้นช่องเลยพร้อมแคปชัน แต่แอปต้องผ่านการตรวจของ TikTok ก่อน ไม่งั้นขึ้นเป็นส่วนตัว · เปลี่ยนมาโหมดนี้แล้วต้องกด ➕ เพิ่มบัญชีใหม่ (ขอสิทธิ์ video.publish) · ติ๊ก “เนื้อหา AI” ได้ (คลิปที่ทำด้วย AI ต้องติดตามกฎ TikTok)
4. **⬆ อัปโหลด** ทีละคลิป หรือ **▶ อัปโหลดทั้งหมด** (เว้นระยะ ไม่เว้น / 1 / 5 / 15 นาที · กดอีกครั้ง = หยุด)
   - แถวคลิปบอกความคืบหน้า: ขอที่อัปโหลด → ส่งไฟล์ → TikTok กำลังประมวลผล → ✓
   - **ติดเพดาน** (กล่องร่างเต็ม / จำกัดต่อวัน): พักบัญชีนั้นในรอบนี้ แล้วลองบัญชีถัดไปให้ทันที · ทุกบัญชีติด = หยุด
   - ไฟล์ใหญ่กว่า 64MB ส่งเป็นชิ้น (ชิ้นละ 64MB)
5. **📜 ประวัติ**: จำว่าไฟล์ไหน (ชื่อ + ขนาด) อัปไปบัญชีไหนแล้ว → ป้าย “✓ เคยอัป” และ **อัปโหลดทั้งหมดข้ามให้** (อยากอัปซ้ำกดปุ่มที่คลิปนั้น) · เก็บล่าสุด 500 ครั้ง
- รายการคลิปอยู่ในหน้านั้นเท่านั้น (ปิดแท็บ = เลือกใหม่ · ประวัติยังอยู่) · ปิดแท็บระหว่างอัปโหลดจะมีเตือน

## ⚠ ควรรู้
- TikTok ไม่ให้แปะลิงก์ Shopee ให้กดได้ — ถ้าจะปักตะกร้าบน TikTok ต้องใช้ **TikTok Shop Affiliate** (คนละระบบกับ Shopee)
- โพสต์ถี่/คลิปซ้ำกันมากเสี่ยงโดนลดการมองเห็น — ใช้การเว้นระยะ และสลับคอนเทนต์
