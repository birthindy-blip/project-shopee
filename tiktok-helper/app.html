👤 บัญชี TikTok

เพิ่มอีกบัญชี: ล็อกอินบัญชีนั้นบน tiktok.com ในเบราว์เซอร์นี้ก่อน (หรือสลับบัญชีในหน้าต่างอนุญาต) · แอปยังเป็น Sandbox = ต้องเพิ่มทุกบัญชีใน Target users ก่อน · คลิปสลับบัญชีทีละคลิป (👉 = คลิปถัดไปไปบัญชีนี้)
ส่งแบบ
อัปโหลดทั้งหมด — เว้นระยะระหว่างคลิป
🔑 ตั้งค่าแอป TikTok (ทำครั้งเดียว · ฟรี)
1) developers.tiktok.com → Manage apps → สร้างแอป (หรือใช้แอปเดิม) → มี Login Kit + Content Posting API · 2) Login Kit → Redirect URI ใส่ลิงก์ด้านล่าง · 3) Sandbox → Target users → เพิ่มบัญชี TikTok ที่จะใช้ · 4) คัดลอก Client Key + Client Secret มาวาง · เก็บในเครื่องนี้เท่านั้น
Redirect URI (คัดลอกไปใส่ในแอป TikTok)

📤 คลิปที่จะอัปโหลด

ลากไฟล์คลิป + ไฟล์ .txt (แคปชัน) มาวางตรงนี้
เลือกโฟลเดอร์ Downloads/ShopeeVideo ได้เลย — จับคู่แคปชันจาก .txt ชื่อเดียวกัน (คลิป -A/-B ใช้แคปชันเดียวกัน) · ตัดบรรทัดลิงก์/พิกัดออก (TikTok กดลิงก์ไม่ได้) · ไม่เอารูป · คลิปที่เคยอัปแล้วมีป้าย “เคยอัป” และไม่ถูกส่งตอนอัปโหลดทั้งหมด
